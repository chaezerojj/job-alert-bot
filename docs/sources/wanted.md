# 원티드 사전 조사

> 조사일: 2026-10-15. 결론: **수집 불가 → 스킵** (→ D-011).

## 조사 결과

| 항목 | 결과 |
| --- | --- |
| robots.txt | 403 — CloudFront WAF가 요청 자체를 차단. 수집 허용 여부 확인 불가 |
| 내부 JSON API | 미발견 — Fetch/XHR 탭에서 Amplitude 분석 SDK 호출만 관측됨 |
| 채용 목록 API | 로그인 세션 쿠키 필요로 추정. 비인증 엔드포인트 없음 |
| 로그인 필요 여부 | 필요 (비로그인 API 없음) |
| Actions에서 접근 | 미테스트 — robots.txt 단계에서 차단 확인됨 |

## 결론

- robots.txt 조회 자체가 CloudFront에 의해 차단되어 수집 허용 여부를 확인할 수 없다.
- 공개 JSON API가 없으며, 인증 없이 접근 가능한 엔드포인트를 발견하지 못했다.
- Playwright + 로그인 세션 방식은 "로그인이 필요한 페이지는 수집하지 않는다" 규칙에 위배되고, 쿠키 만료로 장기 안정성이 없다.
- 공통 규칙("막히면 그 사이트는 끄고 사용자에게 알린다") 적용 → 원티드 수집기 스킵.

상황이 바뀌면(공개 API 제공, 이용약관 명시 허용 등) DECISIONS.md를 갱신하고 재구현한다.
