---

@docs/ROADMAP.md 에서 체크되지 않은 첫 번째 항목을 찾아 진행해줘.

1. 그 항목이 `[사용자]` 표시면 직접 하지 말고, 내가 무엇을 하면 되는지 단계별로 알려주고 멈춰.
2. 아니면 작업 전에 아래를 먼저 짧게 보여주고 내 확인을 기다려:
   - 이번에 할 일 한 줄
   - 만들거나 고칠 파일 목록
   - 끝났을 때 내가 눈으로 확인하는 방법
3. 확인받으면 구현하고, `npm run typecheck && npm test`를 통과시켜.
4. 끝나면 ROADMAP.md 체크박스를 체크하고 "작업 기록" 표에 한 줄 추가해.
5. 설계가 바뀌었으면 SPEC.md / DECISIONS.md도 고쳐.
6. 마지막에 확인 방법과 처음 나온 개념을 짧게 설명해줘.
